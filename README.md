# 算上一卦 🔮

中国传统术数占卜工具。单文件 HTML，零依赖，可离线使用，也能接大模型做深度解读。

**包含**：小六壬 · 梅花易数 · 六爻起卦 · 塔罗牌 · 黄历 · 三法合参

## 一、离线使用（不需要任何配置）

直接双击打开 `算上一卦.html` 即可。全部功能可用：

- 78 张塔罗牌正逆位释义
- 六十四卦白话卦意
- 小六壬六宫详解、梅花体用机理、六爻动爻趋势
- 事项自动分类（感情/事业/财运/学业/出行/健康/综合），占问事项真正参与分析
- 每个占法输出「逐项释义 → 逻辑关联 → 结合所问 → 具体建议」四段式

> 想在手机上用：项目已配好 PWA（manifest + service worker + 图标），可「添加到主屏幕」。
> 或部署到 GitHub Pages：https://yuejingfeng912.github.io/chinese-divination-tool/

## 二、AI 深度解读（可选增强）

在离线解读之上，额外调用大模型生成更深入的针对性分析。

### 🔒 安全设计：你的 API Key 绝不会暴露

这是本方案最要紧的一点。

**纯前端网页直接调 API 是做不到密钥安全的**——只要 key 写进 JS，别人打开你的网页按 F12 就能拿走，然后盗刷你的额度。这在浏览器架构下无解。

所以本项目用了一个**本机中转服务**：

```
浏览器 ──(只传解读请求，无 key)──> 本机服务 ──(带 key 调厂商 API)──> 大模型
                                          ↑
                                    key 只在这里，从不离开
```

具体保障：

| 环节 | 处理 |
|---|---|
| Key 存放位置 | 项目根目录 `.env` 文件，**已被 .gitignore 忽略** |
| Key 是否进 Git 仓库 | **不会**，`.env` 永不被提交 |
| Key 是否下发到浏览器 | **不会**，代理的任何响应体都不含 key |
| Key 是否出现在网页源码 | **不会**，前端只保存「代理地址」这一个字符串 |
| 服务监听范围 | 默认 `127.0.0.1`，**只有本机能访问**，局域网内其他设备也连不上 |
| 代理日志 | 不打印 key |

### 开启步骤

**① 准备配置文件**

复制 `.env.example` 为 `.env`：

```bash
copy .env.example .env
```

**② 填入你的 Key**

编辑 `.env`，填 `LLM_API_KEY`，并把 `LLM_BASE_URL`、`LLM_MODEL` 改成你要用的厂商：

```ini
# DeepSeek（便宜、够用）
LLM_API_KEY=sk-你的key
LLM_BASE_URL=https://api.deepseek.com/v1/chat/completions
LLM_MODEL=deepseek-chat

# 本地 Ollama（完全免费、key 留空、连外网都不需要）
LLM_API_KEY=
LLM_BASE_URL=http://127.0.0.1:11434/v1/chat/completions
LLM_MODEL=qwen2.5
```

支持的厂商（OpenAI 兼容格式）：DeepSeek、MiniMax、通义千问、豆包/火山引擎、Kimi、Ollama、LM Studio 等。

**③ 启动本机服务**

双击 `启动代理.bat`，或命令行：

```bash
node server/proxy.js
```

看到「✓ 服务已启动」即可，保持这个窗口开着。

**④ 在网页里使用**

打开 `算上一卦.html` → 任意占法起卦 → 展开底部「🤖 AI 深度解读」面板 → 点「请求 AI 深度解读」。

面板会自动检测服务状态：
- ✓ 已连接 → 可直接用
- ✗ 未连接 → 提示先启动代理，**离线功能完全不受影响**

## 三、常见问题

**Q：网页提示"未连接到本机服务"？**
A：先启动 `启动代理.bat`。另外浏览器对 `file://` 页面的跨域请求有限制，如果双击打开不行，用本地服务器起一下：
```bash
npx serve .
# 或
python -m http.server 8000
```
然后访问 `http://localhost:8000`。

**Q：端口 8787 被占用？**
A：在 `.env` 里改 `PORT`，同时把网页面板里的「本机代理地址」改成同样的端口。

**Q：能不能把这个服务部署到服务器上，给别人用？**
A：技术上可以，但**请务必注意**：一旦部署到公网，服务就成了一个可以调用你 key 的开放接口，别人可以拿它刷额度。公开部署必须加鉴权、限流、或改用对方的 key。

**Q：不用 AI 功能，需要装 Node 吗？**
A：不需要。Node 只有启动本机代理才用得上，纯离线使用完全不需要。

```
算上一卦.html      主应用（单文件，纯 JS，零依赖）
index.html          GitHub Pages 入口（跳转主文件）
manifest.json       PWA 配置
sw.js               Service Worker（离线缓存）
icons/              应用图标
server/proxy.js     本机 AI 中转服务（key 只在这里）
启动代理.bat        一键启动中转服务
.env.example        配置模板（复制为 .env 后填写）
.env                你的真实配置（含 key，已被 git 忽略，切勿提交）
```
